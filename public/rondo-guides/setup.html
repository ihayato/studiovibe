01
まずこれだけ

この依頼文をAIへ渡す

Rondoのフォルダを開いているClaude CodeやCodexなどの作業AIへ、下の文章をそのまま渡してください。

AIへの初回セットアップ依頼文 
このRondoを初回セットアップしてください。

最初にSETUP.mdとAI_CONSTITUTION.mdを全文読み、書かれている順序と安全ルールに従ってください。

進め方のルール：
- コマンドはすべてあなたが実行し、私には打たせないでください
- まず現在の設定と不足項目を調べ、必要な質問を1つずつしてください
- Cloudflare、Resend、Googleへのログインが必要になったら、該当画面を開いて私にログインを依頼してください
- ログイン後は、Cloudflare、Resend、Google Cloud Consoleの設定画面をブラウザ操作機能であなたが操作し、私に手動設定させないでください
- 特にGoogle Cloud ConsoleのOAuth設定と、Cloudflare／ResendのDNS設定は難しいため、必ずあなたが画面操作してください
- パスワード、確認コード、APIキーなどの秘密値はチャットへ表示させず、安全な入力欄へ私が直接入力できるようにしてください
- ドメインを持っていない場合はCloudflareでの取得を提案し、購入前に必ず私の確認を取ってください
- 課金、ドメイン購入、DNS変更、本番公開など外部へ影響する操作は、実行直前に内容を説明して確認してください
- 公開前検査に合格するまで本番公開しないでください
- 最後に管理画面へのログイン、テスト登録、確認メール、最初の1通、解除リンクまで一緒に確認してください

作業中は、いま何をしているかと、私が次にすることだけを短く案内してください。
依頼後はAIが進行役になります

AIが調査し、必要な場面だけ質問します。コマンド入力や管理画面の手動設定を求められたら、この依頼文のルールをもう一度伝えてください。

02
あなたが決めること

AIの質問に答える

技術用語を覚える必要はありません。あなたの事業について、分かる範囲で答えればAIが設定へ反映します。

聞かれる内容

  • 自分が管理するドメイン（持っていない場合はCloudflareで取得を推奨）
  • 読者に表示する発行者名
  • 送信元に使いたいメールアドレス
  • 管理画面へ入るGoogleメール
  • 登録フォームを置くサイトのURL
分からない項目は「おすすめを提案して」と答える

AIに選択肢と違いを説明してもらい、決めてから先へ進めます。

03
ログインの受け渡し

ログインだけ自分で行い、操作はAIへ戻す

AIが必要な画面を開きます。ログインと本人確認を終えたら、ブラウザを閉じずにAIへ操作を戻します。

あなたが行う操作

  • Cloudflare、Resend、Googleへログインする
  • 2段階認証や本人確認を完了する
  • AIが開いた安全な入力欄へ秘密値を直接入れる
  • ドメイン購入やDNS変更の内容を確認し、実行を承認する
ログイン後にAIへ渡す依頼文 
ログインできました。ここから先の設定は、ブラウザ操作機能で進めてください。特にGoogle Cloud ConsoleのOAuth設定と、Cloudflare／ResendのDNS設定は、私に手動設定させず、あなたが画面操作してください。パスワード、2段階認証、CAPTCHA、決済、最終承認が必要な場面だけ止めて私を呼んでください。
GoogleとDNSは、ログイン後も自分で触らない

Google Cloud ConsoleのOAuth設定やDNSレコードの登録は迷いやすく、入力ミスの影響も大きい作業です。AIのブラウザ操作へ任せ、変更内容の説明と承認だけを行います。

AIへ渡さないもの

パスワード、2段階認証コード、決済情報は自分で入力します。AIへ読み上げたり、チャットへ貼り付けたりしません。

04
公開前の確認

AIの公開前報告を確認する

AIは設定と検査を終えたら、公開前に結果をまとめます。赤い項目が残っていないことを一緒に確認します。

報告に含めてもらうこと

  • 必要なアカウントと接続が揃っているか
  • 公開前検査とテストがすべて成功したか
  • 公開されるURLと送信元名
  • 未設定の任意機能が何か
  • 公開後にあなたが確認する順序
LINEや購入者特典は後回しで大丈夫

最初はメールと管理画面だけで公開できます。任意機能は導入後の設定ガイドで追加します。

05
最初の1通

読者と同じ流れを1周する

AIに画面を開いてもらい、自分のメールアドレスで実際に登録します。ここだけは読者の体験として自分で確認します。

一緒に確認する順序

  1. Googleで管理画面へログインする
  2. 登録フォームへ自分のメールアドレスを入れる
  3. 届いた確認メールのリンクを開く
  4. 最初の1通と解除リンクを確認する
  5. 管理画面へ読者数と配信履歴が反映されたかAIに確認してもらう
ここまで来たらセットアップ完了

次は読者へ見せる文章や配信ペースを、AIと一緒に自分の事業へ合わせます。

次は、AIと中身を整える。

講座名、原稿、安全上限、LINE、特典などを、会話しながら自分の運用へ合わせます。
