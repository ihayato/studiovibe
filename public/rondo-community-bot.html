この Bot について

合同会社日本の田舎は資本主義のフロンティアだ（以下「当社」）は、自社のコミュニティサーバー「明鏡」の購入者限定チャンネル1つを、自社の業務用管理画面「Rondo」で読むために、この Bot を使っています。Bot は読むだけで、投稿・返信・リアクション・管理操作はしません。ほかのサーバーやチャンネルには入りません。

扱う情報

対象チャンネルの投稿のうち、画面の表示に要るものだけを扱います。

  • 投稿者の表示名とアイコン
  • 投稿の本文・時刻・添付ファイル・リンクのプレビュー・返信先の冒頭

読み方と保存

  • 管理画面にログインした人が画面を開いたとき・更新したとき・前の投稿を読んだときだけ、Discord の API から50件ずつ読みます。常時接続や定期的な取得はしません。
  • 投稿の内容をデータベース・ファイル・ログに保存しません。同じ読み込みの繰り返しを避けるため、サーバーのメモリに最新のページは最長1分、前のページは最長10分置き、その後は捨てます。
  • Discord で投稿を消したり直したりすると、次に画面を開いたときから反映されます。

見られる人と使い道

  • 見られるのは、当社の管理画面にログインした運営者と、運営者が招いたチームメンバーだけです。一般には公開せず、第三者に渡しません。
  • 購入者の質問や感想を把握し、サポートや改善に役立てるためだけに使います。AI・機械学習の学習、分析・プロファイリング、広告には使いません。

About this bot

Rondoコミュニティ is a private, read-only Discord bot operated by 合同会社日本の田舎は資本主義のフロンティアだ ("we"). It reads one purchasers-only channel in our own community server so that we can read it inside our internal business dashboard, Rondo. The bot never posts, replies, reacts, or moderates, and it does not join any other server or channel.

Data we handle

Only what the screen needs: author display name and avatar, message text, time, attachments, link previews, and the snippet of the replied-to message.

How we read and store it

  • The bot calls the Discord REST API (50 messages per page) only when a signed-in dashboard user opens the screen, refreshes it, or loads older messages. There is no gateway connection and no scheduled collection.
  • We do not store message content in any database, file, or log. To avoid repeated requests, the latest page is kept in server memory for up to 1 minute and older pages for up to 10 minutes, then discarded.
  • Deleted or edited messages are reflected the next time the screen loads.

Who can see it and why

  • Only our operator and the team members they invite, after signing in to the dashboard. It is never shown publicly or shared with third parties.
  • We use it only to understand customer questions and feedback for support and product improvement. It is not used for AI or machine-learning training, analytics, profiling, or advertising.

Contact

To stop a message from being shown, delete it in Discord or contact us at info@vibe.co.jp.
