プライバシーポリシー

SENRI（センリ）— 月蝕綺譚 外伝の歩数ゲーム

SENRI（以下「本アプリ」）は、歩いた分だけ功徳と小判が貯まる歩数ゲームです。本アプリが扱う情報と、その使い方を説明します。 広告・アプリ内課金・アカウント登録はありません。

取得する情報

  • 歩数と歩いた距離（ヘルスケア）: iOS のヘルスケアから、その日の歩数と歩いた距離を読み取ります。歩数は功徳と小判に換えるためにサーバへ送ります。距離は画面に表示するためだけに使い、サーバへは送りません。ヘルスケアへの書き込みは行いません。
  • 端末が作る口座 ID: 本アプリは初回起動時に無作為の ID を作り、端末内に保存します。この ID は氏名・メールアドレス・Apple ID・端末固有番号とは結びついていません。
  • ゲームの記録: 草鞋・お供・小判・功徳・市場の出品と購入・番付の順位など、遊びの中で生まれる記録をサーバに保存します。
  • 月見台との連携（任意）: 月蝕綺譚の月見台と繋いだ場合に限り、月見台の会員 ID と口座 ID を結びつけます。繋がない限り、本アプリは個人を特定できる情報を扱いません。

使う目的

  • 歩数を功徳と小判に換え、草鞋とお供を育て、市場と番付を成り立たせるため
  • 同じ日の二重計上など、不正な記録を防ぐため
  • 通信の障害を調べ、サービスを維持するため

第三者への提供

取得した情報を第三者に販売・提供することはありません。広告 SDK・行動追跡 SDK・解析 SDK は組み込んでいません。サーバは Cloudflare 上で運用しており、Cloudflare は当方の委託先として情報を保管します。

保存期間

日ごとの歩数の記録は 13 か月で消去します。月ごとの確定値（功徳・順位）と小判の帳簿は、サービス提供中は保持します。本アプリを削除すると端末内の口座 ID は失われ、サーバ上の記録には二度と結びつきません（月見台と繋いでいた場合を除く）。

お問い合わせ

本ポリシーや取得した情報についてのお問い合わせは、App Store の商品ページに記載の連絡先までお願いします。

改定

本ポリシーは必要に応じて改定することがあります。重要な変更がある場合は、本ページまたはアプリ内でお知らせします。
