プライバシーポリシー

SENRI（センリ）— 月蝕綺譚 外伝の歩数ゲーム

合同会社日本の田舎は資本主義のフロンティアだ（以下「当社」）は、歩数ゲームアプリ「SENRI」（以下「本アプリ」）におけるお客様の情報の取り扱いについて、次のとおり定めます。 本アプリは、歩いた分だけ功徳と小判が貯まる歩数ゲームです。広告・アプリ内課金・アカウント登録はありません。

取得する情報

  • 歩数と歩いた距離（ヘルスケア）: iOS のヘルスケアから、その日の歩数と歩いた距離を読み取ります。歩数は功徳と小判に換えるためにサーバへ送ります。距離は画面に表示するためだけに使い、サーバへは送りません。ヘルスケアへの書き込みは行いません。
  • 歩数（Android）: Android では、端末の歩数センサー（身体活動の許可）から今日の歩数を読み取ります。お客様がアプリの設定で「ヘルスコネクトとつなぐ」を選んだ場合に限り、ヘルスコネクトから直近 7 日の歩数（スマートウォッチなど、ほかのアプリが記録した歩数を含みます）を読み取ります。手入力された歩数は数えません。ヘルスコネクトから読み取るのは歩数だけで、ほかの健康データは読み取りません。ヘルスコネクトへの書き込みは行いません。読み取った歩数は、功徳と小判に換えるためにサーバへ送ります。ヘルスコネクトとのつながりは、アプリの設定またはヘルスコネクトの画面からいつでも外せます。
  • 端末が作る口座 ID: 本アプリは初回起動時に口座 ID を作り、端末内に保存します。iOS では無作為の ID です。Android では、端末とアプリの組ごとに OS が割り当てる識別子（ANDROID_ID）を元に、元の値へ戻せない形に変換した ID を作ります（本アプリを入れ直しても同じ口座に戻すため、また同じ端末で口座を作り直して特典を重ねて受け取る不正を防ぐため）。ANDROID_ID そのものはサーバへ送りません。口座 ID は氏名・メールアドレス・Apple ID とは結びついていません。
  • ゲームの記録: 草鞋・お供・小判・功徳・市場の出品と購入・番付の順位など、遊びの中で生まれる記録をサーバに保存します。
  • 月見台との連携（任意）: 当社が運営する会員サイト「月見台」（『月蝕綺譚 -Luna Occulta-』内）と本アプリを、お客様の操作で任意に連携できます。連携は、本アプリから月見台で承認する方法、または月見台の画面から本アプリを開く方法で成立します。連携した場合に限り、月見台の会員を指す内部 ID と本アプリの口座 ID を当社のサーバ上で結びつけます。メールアドレスは、予備の連携方法（メールに届く 6 桁のコードで連携する方法）をお客様が選んだときに限り、コードを送るために当社のサーバへ送信します。本アプリの中には保存しません。連携しない限り、本アプリは個人を特定できる情報を扱いません。月見台側での会員情報の取り扱いは、『月蝕綺譚 -Luna Occulta-』プライバシーポリシー「第2章 会員登録（月見台）と当サイトにおける取り扱い」に従います。

使う目的

  • 歩数を功徳と小判に換え、草鞋とお供を育て、市場と番付を成り立たせるため
  • 月見台と連携した場合に、会員の特典・総合ランキング・引き継ぎに反映するため
  • 同じ日の二重計上など、不正な記録を防ぐため
  • 通信の障害を調べ、サービスを維持するため

第三者への提供

取得した情報を第三者に販売・提供することはありません。月見台は当社自身が運営するサービスであり、連携による情報の結びつけは当社の内部で行われます。広告 SDK・行動追跡 SDK・解析 SDK は組み込んでいません。ヘルスケア・ヘルスコネクトから読み取った歩数を、広告や、第三者への販売・提供に使うことはありません。サーバは Cloudflare 上で運用しており、Cloudflare は当社の委託先として情報を保管します。

保存期間

日ごとの歩数の記録は 13 か月で消去します。月ごとの確定値（功徳・順位）と小判の帳簿は、サービス提供中は保持します。口座 ID の控えと月見台との連携の鍵は、端末の保護された領域（iOS はキーチェーン／Android は暗号化された保存領域）に置きます。iOS では本アプリを削除してもこの控えが端末に残るため、同じ端末に入れ直すと同じ口座に戻ります。Android では、2026年10月以降の版が上記の識別子から作った口座 ID であれば、同じ端末に入れ直しても同じ口座に戻ります（それより前の版で作った口座は、入れ直すと戻りません）。iOS で新しい端末へ移行した場合（端末どうしの移行、iCloud バックアップまたは暗号化したバックアップからの復元）は、控えも新しい端末へ引き継がれます。端末を初期化した場合（Android の識別子も変わります）、Android で別の端末へ移った場合、暗号化していないバックアップから別の端末へ復元した場合は控えが失われ、サーバ上の記録には二度と結びつきません（月見台と連携していた場合を除きます。その場合は、もう一度月見台とつなぐと会員として引き継がれます）。月見台との連携は、本アプリの設定または月見台のアカウント画面からいつでも解除できます。月見台を退会した場合、本アプリの記録は、退会の時点で連携していた端末の口座へ戻し、月見台の会員 ID との結びつきを切ります（戻し先の端末がない場合は削除します）。

データの削除のご請求

本アプリで取得した情報（歩数の記録・口座の帳簿・連携していた場合はメールアドレス）の削除は、いつでもご請求いただけます。次の窓口へ、アプリの設定画面に表示される口座 ID（または月見台に登録したメールアドレス）を添えてお送りください。本人確認ののち、原則 30 日以内にサーバ上の記録を削除し、その旨をご連絡します。
info@vibe.co.jp（件名に「SENRI データ削除」とお書きください）

なお、月見台と連携していない口座は、端末からアプリを削除して控えが失われた時点でサーバ上の記録に結びつく手段がなくなり、日ごとの歩数の記録は 13 か月で自動的に消去されます。
