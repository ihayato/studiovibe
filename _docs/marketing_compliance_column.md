3.  **データ（どう扱うか）：個人情報保護法**

## 1. 景品表示法：「No.1」は命取りになる

「業界No.1」「最安値」「絶対に効く」……。
強い言葉を使いたくなる気持ちは分かりますが、根拠（エビデンス）のない断定は **「優良誤認」** として措置命令の対象になります。

**やってはいけないこと（NG例）：**
*   **根拠なきNo.1**：調査期間や比較対照が不明確なまま「満足度No.1」を謳う。
*   **二重価格の罠**：実態のない「通常価格」と比較して「今だけ50%OFF」と見せる。
*   **ステルスマーケティング**：広告であることを隠して、インフルエンサーやアフィリエイターに宣伝させる。

**【対策】**
*   「言い切る」なら「証拠」を用意する。
*   調査データは、「いつ、誰が、誰を対象に」調査したのかを明記する。
*   インフルエンサー施策では「#PR」等の表記を徹底させる。

> [!IMPORTANT]
> **「みんなやってるから」は通用しません。**
> 競合他社がやっていても、摘発されるときは貴社が最初かもしれません。

## 2. 特定商取引法：LPのデザインは「法律」だ

通信販売（ネット通販）において、**購入完了の直前画面（最終確認画面）** は、ユーザー体験（UX）ではなく「法律上の義務」です。

**やってはいけないこと（NG例）：**
*   **定期縛りの隠蔽**：「初回500円！」と大きく見せて、実は「4回継続が条件（総額2万円）」であることを小さく書く。
*   **解約の迷路**：解約方法を分かりにくくしたり、電話が繋がらない状態にする。
*   **最終確認画面の不備**：申し込みボタンを押す画面で、支払い総額や契約期間が一目で分からない。

**【事例：株式会社VIRTH（2025年6月処分）】**
通信販売における表示義務違反などで、6か月間の **業務停止命令** を受けています。
さらに、代表者個人に対しても **業務禁止命令** が出ています。
「知らなかった」では済まされない、重い処分です。

**【対策】**
*   最終確認画面で、契約の全貌（総額・期間・解約条件）が見えるか確認する。
*   スマホの1画面に収まらない場合でも、重要な条件はファーストビューに入れる。

## 3. 個人情報・データ：使う前に「守る」

「データを活用してターゲティング！」と意気込む前に、そのデータ、本当に安全ですか？
個人情報保護法は年々厳しくなっています。

**やってはいけないこと（NG例）：**
*   **目的外利用**：キャンペーン応募で集めた情報を、同意なく別の事業の勧誘に使う。
*   **委託先の放置**：広告配信や分析を外部に丸投げし、データの扱いをチェックしていない。
*   **クッキーの無断利用**：ユーザーに通知せず、行動履歴を収集して広告配信に使う（電気通信事業法も関連）。

**【事例：LINEヤフー（2024年3月指導）】**
個人データの安全管理措置の不備等について、個人情報保護委員会から行政上の対応を受けています。
大企業であっても、データ管理のミスは致命的な信用毀損につながります。

## 実務で使える「生き残りチェックリスト」

社内稟議やクリエイティブチェックに、以下のリストを活用してください。
これらをクリアしていない施策は、リリースすべきではありません。

- [ ] **【表現】** 「No.1」「最安」「絶対」等の表現に、客観的な根拠資料はあるか？
- [ ] **【広告識別】** 記事広告やインフルエンサー投稿に「PR/広告」の表記はあるか？
- [ ] **【価格】** 「通常価格」の実態はあるか？ 二重価格表示の要件を満たしているか？
- [ ] **【通販】** 最終確認画面で「総額」「契約期間」「解約条件」が一目でわかるか？
- [ ] **【メール】** 配信リストは「同意（オプトイン）」を得たものか？ 解除リンクはあるか？
- [ ] **【データ】** プライバシーポリシーの利用目的に、現在の施策が含まれているか？
- [ ] **【外部送信】** 計測タグやSDKの導入について、ユーザーへの通知・公表を行っているか？
- [ ] **【権利】** 画像・動画・音楽の著作権、人物の肖像権はクリアになっているか？
- [ ] **【医療・健康】** 薬機法の認証範囲を超えた効果効能を謳っていないか？
- [ ] **【事故対応】** 万が一の炎上や漏えい時、誰がどう動くか決まっているか？

## まとめ：コンプライアンスは「足枷」ではない

法律を守ることは、マーケティング活動を制限する「足枷」ではありません。
むしろ、**「長期的に勝ち続けるための土台」** です。

怪しい表現で一時的に売上を上げても、それは砂上の楼閣。
一度の摘発で、全てを失います。

逆に、**「正しく、誠実に、根拠を持って伝える」** ことができれば、顧客からの信頼は積み上がり、ブランドは強固になります。

Studio VIBEも、「クリエイターファースト」「誠実なAI活用」を掲げています。
法令遵守は、その第一歩です。
